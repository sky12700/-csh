最初に、onintr interrupt によって割り込み処理を設定している。プログラムの実行中に Ctrl-C が入力されると、通常の処理を中断し、interrupt: というラベルの位置へ移動する。割り込み処理ではメッセージを表示し、その後 goto menu によってメニューへ戻るようにした。

menu: はメニューを表示する部分のラベルである。利用者が処理を選択した後、それぞれの処理が終了すると goto menu を実行して再びメニューを表示する。このようにすることで、プログラムを終了するまで何度でも作成、コンパイル、実行を繰り返すことができる。

ファイルの存在確認には -e を使用した。コンパイルを行う前に C 言語ファイルが存在するかを確認し、実行する前には実行ファイルが存在するかを確認している。これにより、存在しないファイルを操作したときに発生するエラーを減らすことができる。

コンパイルには次のコマンドを使用した。

compile-command
gcc "$name.c" -o "$name.out"

-o オプションを使用することで、作成される実行ファイルの名前を $name.out に指定している。また、$status の値を確認することで、コンパイルが成功したかどうかを判断している。$status が 0 の場合は正常終了、それ以外の場合はエラーが発生したことを表す。
